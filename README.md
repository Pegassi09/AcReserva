# AC Reserva

Sistema web para gerenciamento e reserva de salas corporativas, desenvolvido para centralizar agendamentos e facilitar o controle de ambientes e recursos compartilhados.

## Funcionalidades

- Cadastro, consulta e cancelamento de reservas.
- Gerenciamento de salas e recursos disponíveis.
- Autenticação de usuários e acesso administrativo.
- Dashboard para acompanhamento das reservas.
- Controle de limites mensais e semanas consecutivas.
- Validação de conflitos de salas e equipamentos.
- Integração opcional com Google Calendar.

## Tecnologias

- **Frontend:** HTML, CSS e JavaScript.
- **Backend:** Python.
- **Banco de dados:** MongoDB Atlas.
- **Hospedagem:** Vercel Functions.

## Demonstração

Acesse a aplicação: https://acreserva.vercel.app/

## Implantação

O projeto pode ser implantado na Vercel, utilizando o MongoDB Atlas para armazenamento persistente. A configuração requer variáveis de ambiente para conexão com o banco de dados e autenticação.

Consulte este repositório para obter o código-fonte e as instruções de configuração.
